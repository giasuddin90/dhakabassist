Using a file in a lesson or quiz
  1. Upload the file to the library as lesson, quiz or download material.
  2. Press Copy beside its Markdown. (Writing the Markdown yourself? Copy the link and use ![description](link) for audio and images.)
  3. Paste into the module's lesson notes, or anywhere in a quiz: the title, a question, an answer option or the explanation. Then save.

Audio becomes a player and SVG or images show as figures. The text in square brackets is the description screen readers announce, so make it say what the figure shows.

Download material, and any PDF, document, score or ZIP, becomes a download link that saves the file instead of opening it.

Files are private. A student can only open a file that is linked from a module (or its quiz) they have unlocked.
