Using a file in a lesson

  1. Upload the file here.
  2. Press Copy beside its Markdown. (Writing the Markdown yourself? Copy the link and use ![description](link) for audio and images.)
  3. Paste into the module's lesson notes and save.

Audio becomes a player and SVG or images show as figures. The text in square brackets is the description screen readers announce, so make it say what the figure shows.

Files are private. A student can only open a file that is linked from a module they have unlocked.
